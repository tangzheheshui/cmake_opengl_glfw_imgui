# 测试验证与性能基准

这份讲：怎么证明两端一致、怎么证明达标。

## 验证开关（环境变量）

| 开关 | 验证什么 |
|---|---|
| RHI_SMOKE=1 | 冒烟三角形（最基础链路） |
| RHI_TEXQUAD=1 | 贴图四边形（纹理） |
| RHI_LINE_TEST=1 | 线（索引缓冲） |
| RHI_CLIP=1 | 剖切平面 |
| RHI_VIEWPORTS=2 或 4 | 多视口 |
| RHI_RT_TEST=1 | 离屏渲染加回读 |
| RHI_PICK_TEST=1 | 拾取 |
| RHI_EXIT_AFTER=帧数 | 跑 N 帧退出（查泄漏） |
| RHI_VK_VALIDATION=1 | 开 Vulkan 验证层（必须 0 错误） |
| RHI_SHADOW_DEMO=1 | 阴影演示（光源下方加投影物，VK 模式可见地面阴影） |
| RHI_VK_MULTILIST=1 | 多命令列表提交顺序（附加列表先、主列表后，回读应为 0xBBBBBBBB） |
| RHI_CMDLIST_CHURN=N | 附加列表创建→录制→销毁 N 轮（验证不累积，附加列表数应为 0） |
| RHI_TEX_CHURN=N | 纹理创建→销毁 N 轮（验证槽位复用，前后槽位数应相等） |

## 关键基准值

| 验证 | 期望结果 |
|---|---|
| 冒烟三角形中心像素 | BGRA 215,140,122 |
| 贴图四边形中心像素 | 精确 180,60,220 |
| 离屏回读 | OpenGL 和 Vulkan 逐字节一致 |
| Vulkan 验证层 | 0 错误 |

## 性能目标

| 项 | 目标 |
|---|---|
| 场景规模 | 2000 个以上绘制不崩 |
| 内存分配 | 按页分配，不是一资源一次 |
| 每帧描述符更新 | 0（CPU 写，帧末统一） |
| 单个源文件 | 不超过 400 行 |
