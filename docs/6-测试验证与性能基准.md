# 测试验证与性能基准

这份讲：怎么证明两端一致、怎么证明达标。

## 验证开关（环境变量）

| 开关 | 验证什么 |
|---|---|
| RHI_SMOKE=1 | 冒烟三角形（最基础链路） |
| RHI_TEXQUAD=1 | 贴图四边形（纹理） |
| RHI_LINE_TEST=1 | 线（索引缓冲） |
| RHI_CLIP=1 | 剖切平面 |
| RHI_VIEWPORTS=2 或 4 | 多视口 |
| RHI_RT_TEST=1 | 离屏渲染加回读 |
| RHI_RT_MSAA=4 | 离屏 RT 用 4x MSAA（需同时开 RHI_RT_TEST） |
| RHI_PICK_TEST=1 | 拾取 |
| RHI_EXIT_AFTER=帧数 | 跑 N 帧退出（查泄漏） |
| RHI_VK_VALIDATION=1 | 开 Vulkan 验证层（必须 0 错误） |
| RHI_LOD=1 | LOD 演示（远处模型换用于顶点聚簇简化网格，日志打印三角形数变化） |
| RHI_SHADOW_DEMO=1 | 阴影演示（光源下方加投影物，VK 模式可见地面阴影） |
| RHI_VK_MULTILIST=1 | 多命令列表提交顺序（附加列表先、主列表后，回读应为 0xBBBBBBBB） |
| RHI_CMDLIST_CHURN=N | 附加列表创建→录制→销毁 N 轮（验证不累积，附加列表数应为 0） |
| RHI_TEX_CHURN=N | 纹理创建→销毁 N 轮（验证槽位复用，前后槽位数应相等） |
| RHI_ASYNC_DEMO=1 | 模型后台预解析（E5：后台 Assimp + future 汇合，两端通用） |
| RHI_PROBE=1 | 第 30 帧回读屏幕采样点打印（渲染链路验证） |
| RHI_DUMP=1 | 第 30 帧整帧导出 PPM（配合 RHI_PROBE；GL/VK 各存 frame_gl/frame_vk.ppm） |
| RHI_CULL_STATS=1 | 每 120 帧打印视锥剔除统计 |
| RHI_VIEWPORT_CAMS=1 | 多相机多视口演示（每 tile 独立相机） |

## 门禁（提交前必跑）

```bash
tools/rhi_gate.sh    # GL 4 项 + VK 5 项（验证层 0 error）+ 分层检查，全过输出 ALL GREEN
```

## 整帧对比（两端一致性）

```bash
# 双端各跑一次（第 30 帧落盘 PPM），再逐像素比
RHI_PROBE=1 RHI_DUMP=1 RHI_EXIT_AFTER=60 ./build-gl/app/Debug/my_app
DYLD_LIBRARY_PATH=/opt/homebrew/lib RHI_BACKEND=vulkan RHI_PROBE=1 RHI_DUMP=1 RHI_EXIT_AFTER=60 ./build/app/Debug/my_app
# 比对 $TMPDIR/frame_{gl,vk}.ppm：场景区差异 <1%（面板区为 ImGui 字体栅格差异，忽略）
```

## 关键基准值

| 验证 | 期望结果 |
|---|---|
| 冒烟三角形中心像素 | BGRA 215,140,122 |
| 贴图四边形中心像素 | 精确 180,60,220 |
| 离屏回读 | OpenGL 和 Vulkan 逐字节一致 |
| Vulkan 验证层 | 0 错误 |

## 性能目标

| 项 | 目标 |
|---|---|
| 场景规模 | 2000 个以上绘制不崩 |
| 内存分配 | 按页分配，不是一资源一次 |
| 每帧描述符更新 | 0（CPU 写，帧末统一） |
| 两端画面 | 场景区逐像素差异 <1%（3200x1800，4x 采样） |
| 单个源文件 | 不超过 400 行 |
