# 后端对照与差异

OpenGL 和 Vulkan 两个后端的差异，以及「哪些已经迁到 Vulkan」。

## 差异对照

| 事项 | OpenGL | Vulkan |
|---|---|---|
| 着色器 | GLSL 直接编译 | GLSL 先转成 SPIR-V |
| 参数传递 | 按名字找（glUniform） | 固定布局：绘制数据进帧内环 + 动态偏移，管线参数走 push constant |
| 纹理绑定 | 绑到纹理单元，立即生效 | 每张纹理自带描述符集，绘制时一次绑 set0 + N 个纹理槽（N 最多 8，按设备描述符集上限裁） |
| MSAA | 采样数由上下文创建时决定，后端只校验 | 交换链外建多采样颜色/深度附件，渲染时 resolve 回交换链图 |
| 颜色空间 | 默认帧缓冲 `GL_FRAMEBUFFER_SRGB`（Pass 边界自动开，UI overlay 经 setSrgbWrite 关） | sRGB 交换链（格式驱动） |
| Pass 边界 | 手动保存、恢复状态（含 sRGB/视口/裁剪/线框） | 天然隔离 |
| 深度语义 | 常规 Pass GL 约定；纯深度 Pass（阴影）内部转 Reversed-Z（清 0 + GREATER） | 全局 Reversed-Z（1=近/0=远） |
| 多视口 viewport | 负高度按目标高换算成 GL 左下原点 | 负高度 viewport 原生支持 |
| 回读行序 | 第一行是画面底部 | 第一行是画面顶部 |
| 文字 | SDF 图集 → RHI 纹理（两端同一实现） | 同左 |

## 迁到哪了

| 功能 | OpenGL | Vulkan |
|---|---|---|
| 模型（贴图/纯色/线框/剖切/透明/LOD）、天空盒、宽线 | 有 | 有 |
| 拾取、多视口、阴影、SDF 文字、MSAA | 有 | 有 |
| 骨骼动画模型 | 没有（RHI 路径未实现，绘制跳过） | 没有（同左） |

业务层去后端化后只有一条 RHI 路径，「哪些迁到哪了」不再是对照表——上表剩下的
是两端都还缺的能力。

## 主要风险

- 每加一个新能力，OpenGL 和 Vulkan 都要实现一遍，成本容易低估。
- 两台机器 GPU 不同，不能逐像素比对，只能靠验证层加结构断言。
